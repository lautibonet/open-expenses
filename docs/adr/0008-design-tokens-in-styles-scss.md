# 0008 - Design tokens in styles.scss with shared SCSS patterns

DESIGN.md ("The Quiet Register") codified the visual system, but components hardcoded its values, so drift was invisible and repeated patterns (form labels, fields, the exchange-rate well, danger buttons) were copy-pasted between features. We declared the full palette, type ramp, corner scale, spacing rhythm, and elevation as CSS custom properties in `src/styles.scss` — the single source of truth — and extracted repeated patterns into `src/app/shared/styles/_patterns.scss` (Dart Sass placeholders consumed via `@use ... as *` + `@extend`), preserving Angular's component style encapsulation. Alternatives rejected: global utility classes (would leak component internals into global CSS) and a third-party token pipeline (violates the zero-dependency, legible-codebase constraint). Consequence: components reference tokens instead of literals, and a new color must join a sanctioned ramp (paper, ink, ink-tint, amber, danger) before it touches a component.
